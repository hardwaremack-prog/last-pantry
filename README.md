# ☢ Last Pantry — Survival Food Finder

A phone-first, offline-capable map for finding and tracking food: game herds, flocks, crop fields, orchards, nut trees, berry patches, wild greens, mushrooms, fishing holes, shellfish beds and water sources.

**Open it:** https://hardwaremack-prog.github.io/last-pantry/

## Features
- 100+ food types in 11 categories, each with season months and safety tips
- **Worldwide regions** (auto-detected from GPS): seasons shift for the Southern Hemisphere and warm or cold climates, and local foods are added (kangaroo, coconut, prickly pear, pinyon, salmon runs, cloudberries…)
- **Sightings** for animals: each one is a map point, so you see herd movement trails plus dawn/day/dusk/night patterns
- **Harvest log** with amounts; statuses Ready, Not ripe yet, Harvested, Picked clean
- "In season now" filter and a full season calendar
- Find-it arrow + distance, Apple/Google Maps directions, satellite view, wasteland map tint
- Photos, backup/restore (.json), spreadsheet export (.csv)
- Installable (Add to Home Screen) and works offline

## Install on iPhone
Open the link in **Safari** → Share → **Add to Home Screen** → allow Location.

⚠️ Follow hunting, fishing and land-access laws. Only eat wild plants and mushrooms you can identify with certainty. Boil or filter wild water.
